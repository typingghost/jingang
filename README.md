# 未然 · 金刚

金刚经三十二品的手机阅读页，配八期播客，可以离线收听。

- 打开：<https://typingghost.github.io/jingang/>
- 首页默认写"亲爱的你们，今天读第几品"，大家共用一个链接就行。想换称呼，可以在链接后面加 `?to=称呼`。
- 在 iPhone 或 iPad 上，用 Safari 打开以后点"分享"→"添加到主屏幕"，就会像一个 App 一样出现在桌面上。
- 首页底部"全部存到本机"可以一次把八期都下载好，之后断网也能听；每一期第一次播放时也会在后台整段存下来。

原本是给家人做的安卓离线 App，这是同一份内容的网页版。由深海基地全员制作。
